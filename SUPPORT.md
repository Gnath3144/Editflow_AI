# Getting Support for Editflow AI

Thank you for using **Codealytica Editflow AI**! Here are the recommended ways to get help, report problems, and ask questions.

---

## 1. Documentation First

Before opening an issue, check the comprehensive documentation:

- **[System Architecture](docs/architecture/SYSTEM_ARCHITECTURE.md):** Deep dive into the modular engine design.
- **[Operations Guide](docs/operations/OPERATIONS_GUIDE.md):** Step-by-step instructions for running post-production and dubbing.
- **[Installation Guide](docs/installation/INSTALLATION.md):** Windows and Linux setup and dependency troubleshooting.
- **[Troubleshooting Guide](docs/operations/TROUBLESHOOTING.md):** Resolving common FFmpeg, PyAV, or Whisper errors.

---

## 2. GitHub Issues

Use [GitHub Issues](https://github.com/respectfulnrespected59-source/qmm-autoedit/issues) for:

- **Bug Reports:** If you encountered an error, unexpected crash, or regression, submit a [Bug Report](.github/ISSUE_TEMPLATE/bug_report.yml).
- **Feature Requests:** If you need a new provider, tool, or capability, submit a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.yml).
- **Integration Requests:** If you want support for a new TTS, translation, or storage provider, submit an [Integration Request](.github/ISSUE_TEMPLATE/integration_request.yml).
- **Documentation Issues:** If documentation is missing, ambiguous, or incorrect, submit a [Documentation Issue](.github/ISSUE_TEMPLATE/documentation_issue.yml).

---

## 3. Asking Questions

For general architectural questions, usage scenarios, or discussion:
- Open a [Question Issue](.github/ISSUE_TEMPLATE/question.yml) on GitHub.

---

## 4. Security Disclosures

For security vulnerabilities or credential issues, please refer to our [Security Policy](SECURITY.md) and do not post publicly.

# Quality Assurance & Acceptance Criteria

---

## 1. 4-Tier Automated Acceptance Gate

1. **Acoustic Gate:** Integrated Loudness `-16.0 ± 0.5 LUFS`, True Peak `≤ -1.5 dBTP`, SNR `≥ 38 dB`.
2. **Translation Gate:** Zero code leakage, 100% technical glossary terms preserved.
3. **Synchronization Gate:** Spoken audio drift `≤ 200ms` relative to on-screen video actions.
4. **Comprehension Gate:** Subtitle sync within `50ms`, reading speed `≤ 17 characters/sec`.

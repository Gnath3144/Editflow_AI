# Translation & Terminology Standards

---

## 1. Code & Technical Shielding

Technical learners require exact programming keywords. The engine utilizes regular expression token shielding prior to translation:
1. Inline code: `` `pip install pydantic` ``
2. Code blocks: ```python ... ```
3. Variable names: `camelCase`, `snake_case`, `SCREAMING_SNAKE_CASE`
4. CLI options: `--output-dir`, `-v`, `--help`
5. Standard library modules: `sys`, `os`, `json`, `subprocess`

---

## 2. Tone and Register

- **Instructional Tone:** Direct, authoritative, patient, and collegial.
- **Second-Person Address:** Use respectful standard second-person (e.g. Hindi *आप*, Tamil *நீங்கள்*, Telugu *మీరు*, Japanese *あなた* / polite *-masu* verb endings).
- Avoid informal slang, colloquial contractions, or patronizing classroom remarks.
